# 南航申请书正文撰写说明

这份说明供修改和搬入模板时使用，不属于申请书正文。

本次题目为“柔性支撑空间机器人耦合动力学与运动振动协同控制”。正文以文件夹内哈工大指南中的机器人运动控制、柔性支撑耦合和模型误差处理为基础，主要对应南航指南2.2“轻质柔性结构动力学设计与分析”，同时对应2.5“闭环系统模型辨识、分析与控制”。

## 文件使用

- `南航开放课题_报告正文.tex`：独立可编译的LaTeX源文件，包含模板报告正文的一、二、三部分。源文件中标明了正文起讫位置。顶部题目可填入Word的“项目名称”。
- `pdf/南航开放课题_报告正文.pdf`：供阅读和核对的排版预览。
- 未填写封面、申请项目简表和签字盖章页；原始Word及PDF材料未修改。
- 使用XeLaTeX编译两次即可。中文采用TeX Live常见的Fandol字体，无需外部图片、BibTeX或专有字体；参考文献与TikZ技术路线图均写在同一源文件中。

## 研究范围如何收窄

南航正文只设置两项研究内容：一是耦合动力学表征与闭环参数辨识，二是参数变化条件下的运动与振动协同控制。地面实验服务于这两项内容，不另立装备研制方向。重点研究单机器人在既定连接构型下携载运动和接触前停驻，采用少量主导模态及敏感参数组织方法。

这不是将原指南逐句替换同义词。南航项目的中心问题调整为“柔性支撑响应能否从闭环数据中有效辨识，以及模型修正如何改善运动与振动控制”。考核增加模态频率、独立响应预测与残余振动指标，突出结构动力学和闭环控制特色。

| 维度 | 南航本次正文 | 哈工大后续可增加的研究内容 |
| --- | --- | --- |
| 作业范围 | 既定连接构型下的携载运动、接触前停驻 | 拾取、转运、对准、接触组装全过程及阶段切换 |
| 动力学复杂度 | 若干预定支撑状态、作业频段内少量主导模态 | 组装推进引起的边界演化、多模块连接变化及更大动态扰动 |
| 模型误差 | 支撑与载荷敏感参数辨识，有限且可重复的残差补偿 | 摩擦、惯量、阻尼、迟滞、传动时延、关节柔性等更广泛未建模效应的协同处理 |
| 感知与接触 | 外部位姿测量服务于反馈和独立校核 | 视觉误差处理、视觉到接触感知过渡、接触状态辨识及自主位姿修正 |
| 控制目标 | 末端运动精度与结构振动的共同改善 | 弱先验接触条件下的稳定装配、柔顺对接及全过程适应 |
| 实验与交付 | 现有条件改装、柔性支撑试件、专项模型和控制验证 | 缩比样机及拾取—转运—组装完整实验系统，独立接触工况与装配成功率评价 |

因此，后续哈工大申请可沿用南航正文中的应用背景和部分共性方法论证，将南航形成的模型、数据和控制方法作为研究基础，重点增写接触操作和全过程问题。若两项均获支持，应按实际任务书明确新增任务、试验数据和成果归属，不能把已经资助的同一任务再次列作新增研究内容。

哈工大现有材料是指南建议，能否形成正式项目尚不确定。本次未将其写成已立项或已承担科研项目，也未擅自修改原指南文件。

## 编写依据和拟定假设

1. 申请人及团队基础暂沿用哈工大材料中的单明贺教授团队。约4米×10米地面平台的描述来自用户提供的材料；学历经历及3项代表性论文补充核对了高校和期刊公开信息。
2. 尚未收到直接执行人员当前算法、设备接口和实测结果，因此没有将拟开展的闭环辨识、残差补偿或抑振方法写成已完成成果。上述方法是围绕原指南主线拟定的研究方案，待具体工作信息补充后可进一步贴合。
3. 南航正式通知列明重点课题约20–30万元、2027年1月至2028年12月执行，本稿暂按30万元测算。预算单价和数量是编制草案，不是供应商报价。专家咨询费1万元，占3.33%；劳务费3万元，占10%，符合本地模板列明的比例上限。[2027年度申请通知](https://skl.nuaa.edu.cn/2026/0905/c4738a409560/page.htm)
4. 5%的模态频率误差、15%的响应预测误差、15%的运动误差改善、25%的振动降低，以及6组工况、每组至少10次配对重复试验，均为本稿拟定目标，不是已有实验结果，也不是南航指南指定的指标。保留“参数偏差±10%、跟踪误差改善15%”作为共性方法评价条件，但没有照搬哈工大的样机尺寸、基座大幅扰动、绝对跟踪精度和装配成功率整套指标。提交前应结合实测基线核定目标强度。
5. 验证采用真实柔性支撑响应、独立末端测量和相同执行时间，避免用预设基座位移回放论证结构抑振效果。若现有平台只能做基座运动回放，需配置柔性支撑试件，或据此修改抑振研究任务及预算。

## 正文中五处待补充事实

1. 直接相关的现有算法和近期实验结果：具体做过什么、实际测试条件、取得什么数值结果。建议补1幅真实实验图或结果图。
2. 南航合作人员与工作条件：固定研究人员姓名、职称、实际分工；现有机器人型号、控制接口、位姿和振动测量条件。申请要求有重点实验室固定研究人员参与，正文没有擅自指定合作人。[开放课题管理办法](https://skl.nuaa.edu.cn/_upload/article/files/87/4c/f46a23944fa080e00343d3d0ab42/a5b84dd3-ff0b-4f2a-abd3-d62caeac4c04.pdf)
3. 奖励完整信息：COSPAR奖对应的论文及证书信息；中国振动工程学会科学技术二等奖的获奖项目、年份、全部受奖人员和本人排序。
4. 实际项目组成员的简介、代表性论著和奖励。不能由共同署名论文直接推定某人参加本项目。
5. 近五年项目清单和各自任务边界。论文致谢中的基金编号不能直接据此认定为申请人本人主持，也不能据此推定项目经费和执行时间。
