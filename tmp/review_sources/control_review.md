# 南航正文技术与实现证据审阅（只读）

审阅对象：`output/南航开放课题_报告正文.tex`。依据包括 RA-L 投稿稿 `26-5356_01_MS.pdf` 的文字提取、`fr3-control`、`libfranka-fr3`、`MOB-net-fr3` 中实际实现及文档。本次没有修改正文/控制代码、编译代码或运行真机。以下行号以当前原稿为准。

## 总体判断

当前正文技术主线基本准确，且已较好地区分了“已有 Panda 固定基座 DDP 残差强化学习”“已有 FR3 倒置建模—SE(3)—QP 及监督学习 GRU 接口”“拟开展柔性支撑闭环融合”。未发现需要推翻方案的确定性公式符号错误。最有价值的修改是加强新增研究必要性和物理量定义，收窄整体稳定性承诺。

## 优先修改

### 1. 用已有结果的局限写实新增研究动机（建议优先）

- 正文位置：83、325–349 行，尤其 349 行。
- 事实：表 V Held-out 的位置/姿态/关节指标抄录准确。同期实测关节力矩变化率 RMS，已有方法为 37.755 N·m/s，名义 DDP 为 28.450，摩擦补偿 DDP 为 28.102，分别高约 32.7% 和 34.3%。表 VI 双端点相对 ZOH 的指令力矩变化率 RMS 为 36.273 vs 46.711 N·m/s，下降约 22.3%。两类对比并不矛盾；后者不能证明相对名义基线减振。
- 风险：仅强调跟踪改善和双端点平滑，会使“为什么还需要研究柔性振动”缺少来自本人工作的最强证据。稿件没有柔性结构振动实验，不能从上述力矩率直接推断结构已经发生振动放大。
- 可替换文字：

  > 已有残差学习在固定基座条件下明显改善了跟踪精度，但其测量力矩变化率并未低于名义 DDP 基线；双端点接口的平滑优势目前主要体现在与零阶保持残差的对比中。这表明提高执行精度尚不能等同于减小柔性结构激励，需进一步把安装界面响应、主导模态能量和总力矩约束纳入残差学习与闭环评价。

- 分类：原文不是错误，是关键论证缺失。

### 2. 补足“真实动力学—命令侧补偿—QP”三者的物理关系

- 正文位置：198–210、226 行。
- 现有公式 `Mhat a+hhat=S^T(z-d)+J_b^T w_b` 与当前代码完全一致，不应改成加号：`fr3-control/include/fr3/controllers/base_tracking_qp.hpp:44–48` 和 `src/controllers/base_tracking_qp.cpp:369–371` 明确 `z` 是含补偿的命令等效总量，`z-d` 是名义模型所需力矩。最终发送时恢复关节顺序并扣除 SDK 重力项，见 `experiments/circle_bird/src/control_step.cpp:611–625`。
- 需澄清：目前只写名义 QP 式并称“实际偏差单独保留”，尚不够直观。读者可能误解为真实物理动力学也无条件接受 `z-d`。应明确 `d` 估计的是需要由命令弥补的驱动通道等效失配，而物理执行使用总指令 `z` 经实际接口映射后的力矩；当 `d` 逼近真实匹配失配时，名义加速度预测才接近实际。
- 可在 208 行后补：

  > 这里的减项是名义预测模型与命令补偿之间的接口定义。真实系统接收总指令经执行接口映射后的关节力矩，学习残差用于逼近驱动通道内的等效模型与执行失配；其估计误差及未落入驱动子空间的广义扰动在闭环分析中单独保留。

- 如进一步给实际等效模型，可写 `Mhat a+hhat=S^T(z-delta_tau)+J_b^T w_b+r_perp`，定义 `delta_tau` 为匹配失配、`r_perp` 为未匹配误差，再说明 QP 以 `d` 近似 `delta_tau`。不要把所有惯性/支撑误差都强行压成七维关节残差。
- 分类：需澄清，现有负号正确。

### 3. 将全系统稳定性承诺收缩成可完成的局部结论

- 正文位置：162、236、252、283、295–296 行。
- 风险：252 行同时承诺约束切换、未保留模态、状态估计误差、时延、残差和软跟踪的整体最终有界充分条件，研究跨度明显大于“在现有基础上融合”的表达。奖励中惩罚模态能量、QP 惩罚下一拍模态速度都不自动推出真实模态能量单调下降。`QP 可行` 的逐点假设也不同于递归可行性证明。
- 建议替换 252 行后半段：

  > 首先在固定连接构型、主导模态模型和局部可行工作域内，分析残差估计误差、状态估计误差及加速度跟踪松弛对闭环能量的影响，给出误差最终有界的充分条件及补偿增益范围。进一步将模态截断和采样时序影响作为有界扰动评估稳定裕度，并通过约束切换与延迟工况检验结论的适用范围。

- 若确有精力证明切换系统，应保留为“进一步研究”，不宜和主交付绑定。名义闭环稳定/可行工作域的验证需列为第一阶段任务。
- 分类：拟研究可接受，但承诺偏满。

### 4. 在阶段一明确校核现有 SE(3) 微分约定

- 正文位置：214、271、289–290、319 行。
- 实现证据：`fr3-control/experiments/circle_bird/docx/sensor_fusion_gru_se3_qp.tex:284–296` 已记录左右 Jacobian 及方向导数项存在待核对差异。当前 `src/controllers/se3_impedance_controller.cpp:221–236` 定义 `E=T_current^{-1}T_desired`、`e_V=Ad_E V_d-V`，但使用 `dexpInvSE3(-lambda)`；278–284 行亦保持该计算约定。按该几何模块的 `dexpSE3` 定义，自洽求导应匹配对应左平凡化误差。这个差异不能因程序已有实验入口而忽略。
- 原文仅称已有六维参考加速度实现，本身成立。不要把此已有实现直接用作“理想阻抗储能证明已成立”的证据。
- 建议在 290 行补“完成 SE(3) 微分约定、坐标变换和驱动力矩映射的一致性校核”。申请文本无需展开源码问题；内部实施计划要保留这项校核。
- 分类：确定存在文档已记录的实现/理论待核对项；不是现有申请正文公式的确定错误。

## 次优先修改

### 5. 双端点插值不要暗示跨区间自动连续

- 正文位置：180、242–248、146 行。
- 依据：RA-L 稿式 (10) 对当前起点按上一末端和当前预测起点做滤波，通常并不满足 `dbar_j^0=dbar_{j-1}^1`；式 (11) 区间内分段线性，但跨区间连续性不由插值公式自动保证。
- 当前“相邻区间衔接……在训练及验证中覆盖”是合理的。若继续用“平滑执行”，建议改为“区间内插值执行并约束总力矩变化”，或补“跨区间跳变由衔接条件和总指令变化率限制共同处理”。
- 指标比较总指令变化率合理，但最好同时记录高频力矩谱与主导模态附近的能量；RMS 下降不能保证共振频段激励下降。
- 分类：表述精确性，不是现有结果错误。

### 6. 把 QP 接口复用与新增学习问题分开

- 正文位置：125、226、283、353–355 行。
- 证据：现有总力矩预算内 GRU 接口已实现，不能把“残差先入 QP”独立包装成首次提出的核心创新。正文 353 行已如实说明，有助于可信度。
- 建议突出新增内容：由固定基座轨迹局部价值引导，转为柔性支撑中末端误差与结构响应共同引导；研究受约束 QP 改变残差执行映射后的训练和分析。固定基座 GRU 仅作监督学习对照；不应将 GRU 与 RL 描述成同一策略。
- 分类：创新性论证需进一步聚焦。

### 7. 将误差界和实验工况对应起来

- 正文位置：133–152、258–267 行。
- `主要惯性参数±10%建模偏差` 尚需说明是仿真随机化、人为偏置控制模型，还是由实体负载标定得到。不要让评审理解为每个真实惯性参数均可独立实物调节 ±10%。随机化后的惯性应满足物理可实现条件。
- 建议写“仿真中覆盖经标定确定的参数扰动范围，地面通过已知载荷变化及控制模型参数偏置形成可重复失配”，并用预实验确定具体范围。
- 所有六组工况逐项均满足 20%/25%/15% 的指标严于总体平均，当前原文明确“均值分别评价”。若缺先导数据，应先标注为建议指标，正式申请前根据预实验收敛。
- 分类：需澄清，数字未被既有柔性试验支撑。

## 建议保留的准确边界

1. 倒置建模是动力学树换根，不是物理安装端被移动或取消；根为作业端侧 link7，支撑仍在 link0。当前映射是 joint7…joint1 反序，并非笼统加负号。正文 198、319 行基本准确。
2. 已有 QP 采用末端六维加速度软跟踪，动力学等式和驱动约束为硬约束；柔性模态、界面载荷作为决策量是本项目拟增加的内容。当前静态支撑只解重力平衡，并未联立完整安装界面动态相容条件。正文 321 行准确承认这一点。
3. 已有 Panda RA-L 投稿稿不是发表论文；其表 V 数值、100 Hz 策略与 1 kHz 控制频率、PPO、时序编码、逆动力学辅助监督和双端点说明均有稿件支持。
4. 既有固定基座数据不能直接证明 FR3 柔性支撑迁移。正文 345、349、355、367 行的区分值得保留。
5. 当前 GRU 为监督学习，MOB 是测量侧动力学观测，二者物理量和补偿方向不同；`MOB-net-fr3/GRU输入构成.md:111–122` 还明确当前 GRU 不输入实测力矩、上一用户命令和关节跟踪误差。正文没有误写这些输入。
6. 本次只核查了实现与材料证据，未重新运行测试或完成真机性能验收；不应将这些只读核查当作新增实验结论。
